# MiniRaycast

Быстрый и легковесный десктопный лаунчер для Windows в стиле Raycast и Spotlight.

## Возможности

- **Системный трей**: приложение сворачивается в область уведомлений Windows (трей) и не мешает в панели задач.
- **Глобальные горячие клавиши**: вызов по `Alt + Space` (или настраиваемой комбинации) из любого полноэкранного или оконного приложения.
- **Смена горячих клавиш на лету**: переключение комбинации клавиш через меню трея (`Alt + Space`, `Ctrl + Space`, `Alt + K`, `Ctrl + Shift + Space`) или прямо из поисковой строки лаунчера.
- **Поиск приложений**: сканирование меню «Пуск» (`.lnk` ярлыки), системных утилит и рабочего стола.
- **Математический калькулятор**: вычисление сложных выражений, тригонометрии, корней и степеней.
- **Конвертер валют и единиц**: оффлайн-конвертация популярных валют (`USD`, `EUR`, `RUB`, `GBP`, `CNY`) и физических величин (длина, масса, объемы данных, температура).
- **Системные команды**: управление блокировкой экрана, спящим режимом, громкостью, очисткой корзины и питанием ПК.
- **Текстовые утилиты**: кодирование Base64, реверс текста, смена регистра, подсчет длины строки.
- **История и ранжирование**: сохранение частых запусков и истории запросов в локальной SQLite базе данных.

## Архитектура и стек

- **Rust (Tauri v2)**: ядро приложения, регистрация глобальных хоткеев, иконка в трее с контекстным меню, низкоуровневый перехват фокуса Windows API, сканирование ярлыков и взаимодействие с системой.
- **TypeScript & CSS**: быстрый пользовательский интерфейс с поддержкой клавиатурной навигации (`↑`, `↓`, `Enter`, `Esc`).
- **Python & Lua**: модульная система плагинов (`plugins/`):
  - `calculator.py`: вычисление выражений.
  - `currency.py`: конвертация валют.
  - `units.py`: преобразование единиц.
  - `timer.py`: парсинг таймеров.
  - `text_tools.py` / `text_tools.lua`: текстовые преобразования.
- **PowerShell**: сценарии управления системой и упаковки сборки (`scripts/system_controls.ps1`, `scripts/package_release.ps1`).
- **SQLite**: локальная база данных истории запросов, настроек хоткеев и счетчиков запусков (`database/schema.sql`).

## Горячие клавиши по умолчанию

- `Alt + Space`: показать / скрыть окно лаунчера.
- `↑ / ↓`: перемещение по списку результатов.
- `Enter`: открыть приложение, выполнить команду или скопировать результат вычисления в буфер обмена.
- `Esc`: очистить строку поиска или свернуть лаунчер в трей.

## Управление через системный трей

- **Левый клик по иконке в трее**: открыть / скрыть лаунчер.
- **Правый клик по иконке в трее**:
  - `Show MiniRaycast`: открыть окно.
  - `Change Hotkey`: выбор активного сочетания клавиш (`Alt + Space`, `Ctrl + Space`, `Alt + K`, `Ctrl + Shift + Space`).
  - `Quit MiniRaycast`: полное завершение работы программы.

## Запуск готового .exe

Собрать и упаковать портативную версию:
```powershell
powershell -ExecutionPolicy Bypass -File scripts/package_release.ps1
```

Готовый файл запускается из папки `release-portable/MiniRaycast.exe`. При запуске он сразу сворачивается в трей и доступен по горячей клавише.

Структура портативной папки:
```text
release-portable/
├── MiniRaycast.exe             # Исполняемый файл лаунчера
├── WebView2Loader.dll          # Системная библиотека загрузчика WebView2
├── plugins/                    # Python/Lua плагины
└── scripts/system_controls.ps1 # Скрипт системных команд
```

## Сборка из исходников

1. Установка зависимостей:
```bash
npm install
```

2. Сборка фронтенда:
```bash
npm run build
```

3. Сборка бинарника:
```bash
cargo build --release --manifest-path src-tauri/Cargo.toml
```
