# MiniRaycast

Быстрый и легковесный десктопный лаунчер для Windows в стиле Raycast и Spotlight.

## Возможности

- **Глобальный хоткей**: активация по сочетанию клавиш `Alt + Space` с мгновенным перехватом фокуса окна.
- **Поиск приложений**: автоматическое сканирование меню «Пуск» (`.lnk` ярлыки), системных утилит и рабочего стола.
- **Математический калькулятор**: вычисление сложных выражений, тригонометрии, степеней и корней.
- **Конвертер валют и единиц измерения**: оффлайн-конвертация популярных валют (`USD`, `EUR`, `RUB`, `GBP`, `CNY`) и физических величин (длина, масса, объемы данных, температура).
- **Системные команды**: управление блокировкой экрана, спящим режимом, громкостью, очисткой корзины и питанием ПК.
- **Текстовые утилиты**: кодирование Base64, реверс текста, смена регистра, подсчет длины строки.
- **История и ранжирование**: сохранение частых запусков в локальной SQLite базе данных.

## Архитектура и стек

- **Rust (Tauri v2)**: ядро приложения, регистрация глобальных хоткеев, низкоуровневый перехват фокуса Windows API, сканирование ярлыков и взаимодействие с системой.
- **TypeScript & CSS**: быстрый пользовательский интерфейс с поддержкой клавиатурной навигации (`↑`, `↓`, `Enter`, `Esc`).
- **Python & Lua**: модульная система плагинов (`plugins/`):
  - `calculator.py`: вычисление выражений.
  - `currency.py`: конвертация валют.
  - `units.py`: преобразование единиц.
  - `timer.py`: парсинг таймеров.
  - `text_tools.py` / `text_tools.lua`: текстовые преобразования.
- **PowerShell**: сценарии управления системными службами (`scripts/system_controls.ps1`).
- **SQLite**: локальная база данных истории запросов и счетчиков частоты запусков (`database/schema.sql`).

## Горячие клавиши

- `Alt + Space`: показать / скрыть окно лаунчера.
- `↑ / ↓`: перемещение по списку результатов.
- `Enter`: открыть приложение, выполнить команду или скопировать результат вычисления в буфер обмена.
- `Esc`: очистить строку поиска или свернуть лаунчер.

## Запуск в режиме разработки

1. Установка зависимостей:
```bash
npm install
```

2. Запуск приложения:
```bash
npx tauri dev
```

3. Сборка дистрибутива:
```bash
npx tauri build
```
